CENERI DI GUERRA - COME COMPILARE IL DLL (GitHub Actions)
=========================================================

Questo zip contiene i sorgenti C++ del plugin SKSE, versione 1.2.0 (stessa struttura di
BladeFireMode). La 1.1.5 l'hai compilata tu; la 1.2.0 cambia Menu, Settings, Catalog e main
e svuota Controls.cpp/.h (il remapping dei tasti e' stato tolto). Io non posso compilarla:
se compaiono errori, incolla qui il log.
Se hai gia' un repository, basta sostituire la cartella src (e xmake.lua): Controls.cpp e
Controls.h nel pacchetto sono VUOTI apposta, cosi' non serve cancellare niente (puoi anche
cancellarli).

PASSI
1. Crea un nuovo repository PRIVATO su GitHub (nome a piacere, es. CeneriDiGuerra).
2. Carica TUTTO il contenuto di questo zip nella radice del repository,
   compresa la cartella nascosta .github (se usi "Add file -> Upload files"
   trascina le cartelle src e .github e il file xmake.lua).
3. Vai nella scheda Actions: il workflow "Build" parte da solo a ogni caricamento
   (oppure premi "Run workflow").
4. Quando e' verde, apri l'esecuzione e scarica l'artefatto "CeneriDiGuerra-dll".
5. Dentro trovi  SKSE\Plugins\CeneriDiGuerra.dll  (e il .pdb).
   Copia il .dll in  SKSE\Plugins  della mod "Ceneri di Guerra" in MO2.

SE LA COMPILAZIONE FALLISCE
Apri il passaggio "Build" rosso, copia le righe con "error" (di solito sono poche)
e mandamele: sistemo i sorgenti e ti passo lo zip aggiornato.

NOTE TECNICHE
- Usa CommonLibVR (fork di CommonLibSSE-NG) alla revisione
  dbb86c2523fae0cc70de074f3e2d1a6b657758dc, gia' fissata nel workflow.
- Comando: xmake f -y -p windows -a x64 -m releasedbg --skyrim_vr=n
- Il menu si lega a SKSE Menu Framework in esecuzione (GetProcAddress), quindi
  non servono librerie aggiuntive. Tutte le scritte del menu sono ASCII.
- Moduli: Settings (INI), Catalog (elenco mosse da CeneriDiGuerra_catalogo.tsv),
  Input (lettura pad/tastiera in un thread a 16 ms, 3 slot, rebind), OAR
  (condizione personalizzata "CeneriTrigger" con parametro "Move ID"),
  Arts (macchina a stati: stop, evento di avvio, conferma OAR, blocco comandi,
  catene), Menu (pagine F1).
- Punti non verificati contro le API vere (possibili errori di compilazione; erano gia' nella
  1.1.5 che hai compilato, tranne le parti nuove del menu che usano solo funzioni gia' collegate):
  TESObjectWEAP::GetWeaponType / RE::WEAPON_TYPE, MagicTarget::HasMagicEffect,
  Actor::AsMagicTarget, TESDataHandler::LookupModByName, ControlMap::AreControlsEnabled.
